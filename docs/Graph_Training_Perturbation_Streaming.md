# 图训练扰动的流式聚合接口

固定225次真实执行与核验已完成，累计真实673基础/36校准。详见[真实结果](Graph_Training_Perturbation_Results.md)。本固定问题关闭，后续复用；构造验收与真实研究分别记录，后续复用已有结果。

本接口支撑研究主线第2→3→4环节：检验既有三臂图模型对训练人员删样的预测与解释敏感性。它复用[已验收的受控拟合和跨参考原语](Graph_Training_Perturbation_Primitives.md)，在现有 `research_runtime.graph_explanation` 内增加 `evaluate_training_perturbations`，不新增优化器、源表读取器、参数加载器或HTTP入口。真实研究结果与软件验收分别记录；模拟矩阵通过不表示225次真实拟合已完成。

## 调用与边界

调用方提供已独立核实的内存队列、原五折、45份外折候选元数据、受信加载回调和原三臂聚合结果。入口默认1160人、十变量、两原因24月CIF，要求输入指纹一致。候选只接受原协议三臂、三种子及五折的完整唯一组合，角色为 `GRAPH_OUTER_VALIDATION`，包含 `outer_fold`、`seed`、`arm`、`sha256`、`scope_identity` 和 `training_input_sha256`。最终模型角色被拒绝。

加载回调必须使用原 `load_graph`，核对实际解析字节的SHA、scope、训练输入、原生源码和协议及软件锁；候选字段存在不代替实际归档核验。内存编排再次核对模型角色、种子、协议、网络、训练身份及对象不复用。全部45份旧外折预测的24项两原因OOF hash和12项AD Brier必须在第一个新拟合之前通过，含每个种子和等权均值的Brier。缺门槛或失败即停止。

生产路径调用原 `graph_training.fit_graph_subjects`，共225套基础管线，包含各自训练内插补/标准化；不拟合校准、内折、最终模型或局部回归。替换拟合回调仅允许显式 `constructed=True`，此时返回 `predictive_fits=null` 和构造状态，模拟槽位数不能计入真实或人工优化拟合账本。`constructed` 是测试标签，不是权限或临床准入。

宿主仍负责一次读取、同缓冲区、来源/折/权重及源码版本绑定、独立调用账本和父进程硬资源监督。模块不自行授予临床读取或训练权限；没有持久化授权、真实启动或部署行为。

## 平均、分解与分母

原五折内按事件分层保留80%训练人员，五次固定抽样，九个配对模型共用同一子集。三臂对应种子的初始化、批次日程和输入相同；九模型的原量纲参考、均值和尺度相同。原/新参考都来自对应训练人月，测试值和缺失不改动。

每种子分别计算原模型/原参考A、新模型/原参考B、原模型/新参考C、新模型/新参考D，各保留正反序、双侧海马联合组和两原因。三种子的有符号贡献先等权平均，再计算M=B−A、R=C−A、I=D−B−C+A及T=D−A。逐项验证T=M+R+I；解释重构误差不超过1e-12。L1、绝对CIF漂移、排名和Brier均在平均之后计算，不能先取绝对值或平方后平均。

风险漂移、M/R/I/T向量L1和配对差始终使用全部测试人员，跨折合计原1160人。两项比较固定为prior−self_only和prior−semantic_permutation。五次重复和两个顺序分别报告，其他原因及逐种子诊断只作描述。新模型AD Brier使用原完整训练折KM/IPCW权重，作为性能背景，不重开旧图增益比较。

排名限定共同观测且相对参考发生变化的组。model比较用原参考active组，reference/total比较进一步取全部五次新参考active组的交集。每个原因、比较和Spearman/Top1/Top2指标，再对三臂×两顺序×五重复取共同合格人员，固定分母。少于3组、常量秩、1e-12首位并列、Top2边界并列分别计数；Top2内部并列可用。输出明确给出合格/不合格人数。符号变化只在双方绝对贡献均大于1e-6时计数，不把零贡献当方向翻转。

## 预算与输出

225次拟合分别记录尝试、返回和验收；每次CIF记录尝试/完成及状态行。720个单模型/参考游戏对应240个三种子均值游戏，每游戏17次CIF，原A游戏按折复用；加旧45和新225模型完整预测及结束重放共12,780次CIF。1160人时为2,964,960个状态行、71,159,040个人月推理行。

错误即止，保留已尝试数，不补抽、不换种子、不自动重试。CIF及状态行预算在下一次调用前检查；拟合前后核验单次300秒/累计14,400秒，整体6小时/2GiB为停止上限。模块软检查不能替代父进程硬停止。

旧45模型先完成全部前置门槛，再逐折释放；新子集模型逐个使用和释放，不保留225份参数。只保留当前折进行固定排名分母所需的贡献，跨折保留标量用于准确计算分布分位数。返回聚合分布、共同分母、失败资格计数、账本和方法限制，不返回个人数组、个人hash、模型或参数，不自行写文件。

只有两项AD风险漂移差在五重复全部为负，才能报告本固定扰动中一致较小；解释还必须两顺序同时满足。该判据不产生总体/个人置信区间，也不证明准确性、图增益、唯一解释、个人因果或临床效能。五个原竞争事件、回顾性来源和未识别因果目标的限制保持。

```powershell
.venv-research-graph/Scripts/python.exe -B -m unittest research_runtime.tests.test_graph_perturbation_streaming -v
```

检查使用解析概率回调，不读取临床文件或旧权重、不执行优化器。完整90人模拟核对225槽位、720游戏、12,780次CIF、230,040状态行和5,520,960个人月推理行，并核对全部门槛先于拟合、平均顺序、共同分母、参数释放与失败停止。人工模型中位数仅为模拟参考，不能替代原生训练人月预处理的验收；原生九次人工拟合的既有验收直接复用，不因本命令重跑。

源码可用、构造验收、单次真实执行准入与真实科研结论是不同阶段。225次真实图训练扰动已完成单次执行及聚合核验，旧图增益阴性和个人解释敏感性保持。
