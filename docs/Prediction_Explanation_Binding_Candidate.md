## 复用选择

直接复用 `constructed_pair`、`BoundPredictor`、`authorize_once`、`run_in_memory` 和 `group_shapley.exact_values`。没有复制Shapley算法，也不修改原计算源码。

`table_explanation` 已能检查表格管道、读取内存中的训练参考、绑定诊断状态并调用原CIF；但它需要经核验的实际管道和保存统计。本轮的P2真实宿主证据仍为NOT_EVALUATED，不能用人工字典代替真实模型运行该适配器。通用NumPy核接受明确的预测回调与参考，足够完成本轮范围。LIME会涉及局部替代回归，本轮不执行，输出为null和`NOT_EVALUATED_NO_LOCAL_FIT`；这不推翻既有LIME实现或已关闭的研究。

## 人工范围与真值

[样例](../research_runtime/examples/prediction_explanation_candidate.py)只使用一个虚构十变量记录及其双侧MRI同时缺失的人工变体。模型身份沿用`logistic`元数据夹具，但实际回调是下述解析公式，**不是逻辑回归或真实风险模型**。来源、日期、参数摘要、权限及参考全部人工构造。

令 a=(age−60)/20，m=(30−MMSE)/10，h=(7000−左海马−右海马)/2000，双侧缺失时本人工公式令h项为0；这是公式定义，不是把输入null补成零。AD输出为0.10+0.02a+0.04m+0.03h+0.01am，其他原因输出为0.04+0.01a。公式只为本样例的替换状态定义，不提供临床取值范围支持。

人工参考仅将年龄/MMSE/双侧MRI改为60/30/3500/3500，其余保留；缺失变体保留双侧null。它不声称来自训练中位数。沿用表格九组含双侧海马联合组，原有列顺序与单位保留；全观测仅3组变化、8个子集，缺失变体2组变化、4个子集。

全观测预测为AD=0.1379、其他原因=0.046，参考为0.10/0.04。独立解析归因真值：年龄0.0132/0.006，MMSE 0.0172/0，双侧海马0.0075/0，其余为0；年龄与MMSE各分得一半交互项。缺失变体AD=0.1304，双侧组归因为0；dummy的零不代表缺失或海马没有临床效应。

## 绑定与拒绝

在预测和解释之前，由人工宿主固定一份expected依据，返回对象不能相互为对方背书。候选记录：

| 依据 | 本轮检查的范围 |
| --- | --- |
| 输入与上下文 | 完整请求、人工trusted_context的规范JSON摘要；同一对象/日期/快照/可用性策略；解释实际观测矩阵另核摘要 |
| 模型 | 12字段身份、特征顺序、人工公式参数/recipe token；同一解析函数用于原观测预测和替换状态 |
| 输出 | 固定24月、raw_uncalibrated_24month_CIF、AD/其他原因顺序；原dispatch须COMPLETED且已消费人工许可；两原因值与解释端点按绝对1e-12核对 |
| 解释参考 | 明确人工参考策略、原量纲值、规范JSON摘要、组/列顺序和单位；计算所用参考/观测保留副本并核对，不仅比较相同标签 |
| 归因 | 原精确分组方法、非因果标记、有限值、形状、参考概率、加和重构；不摊平残差或补造LIME结果 |

摘要算法仅为sort_keys=True、separators=(',', ':')、ensure_ascii=False、allow_nan=False的UTF-8 JSON SHA256。它与原文件/归档/Git对象摘要不是同一对象。样例中的个人级摘要只针对虚构记录公开；这不是允许真实个人摘要进入公共报告的规则。

`_join_constructed`仅为这个固定人工案例的断言助手，没有任意来件的Schema/资源/认证边界，不能移到服务中当生产校验器。元数据一致、内容摘要与加和重构均不能认证真实来源，也不能防御控制整个Python进程的调用方重贴标签或伪造证据。实际参数到artifact、代码/锁到执行环境、保存训练参考到模型的证据仍须由独立宿主建立；人工recipe token只覆盖人工参数与配方标签，不是执行代码证明。参考替换不是干预或条件分布，归因不识别个人病因/治疗效果。

## 运行与验收

只需已有NumPy锁版本2.4.6，无pandas、sklearn、Torch或模型文件。在仓库根目录、现有NumPy环境运行：

```powershell
python -B -m research_runtime.examples.prediction_explanation_candidate
python -B -m unittest research_runtime.tests.test_prediction_explanation_candidate -v
```

[固定人工JSON](../research_runtime/examples/prediction_explanation_candidate.json)与实际全观测输出对应。16项检查覆盖独立解析真值、双方同时换模型仍与外部expected错配、快照/上下文/策略/状态/单位/组/参考错配、仅改参考或观测实际值、失败/无权限结果、对象/预测端点/重构不一致、非有限值、返回副本及缺失保留。

Windows/Python3.11.9与3.12.13在必要源码副本、原锁NumPy环境分别16项通过；每进程仅2次人工dispatch、12次Shapley子集回调、14次解析函数调用，0真实参数加载/原CIF/风险拟合/校准/局部回归。固定JSON另在生成时运行1个全观测人工游戏；不计为真实研究。两个进程的固定JSON核心内容均与实际输出相同。执行守卫无拒绝，不读取临床/私有折，不重跑旧矩阵。

P1/P2/P3的本地候选终点至此关闭。真实模型绑定、训练参考证据、权限来源、Java保存及患者用途均未建立；需要具体独立宿主证据/调用反馈后再限定接入验收，不能靠继续增加报告层关闭。真实科研仍待适用行动/未邀约分母/首次可用历史新来源及ADNI实质回复；673/36、旧图阴性、结构不可估、CSF NO_GO和阈值SUPPRESSED保持。
