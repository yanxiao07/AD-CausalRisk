# 新研究模型的Python接入准备

后续[Python接入候选](Research_Model_Integration_Candidate.md)已将旧业务字段与新七/十变量输入、模型身份、许可及输出逐项对照，并提供现有API的人工样例。它是调用方评审材料，不表示新HTTP/Java链已实现；可获得性对照仍不进入现有内存准入。

固定七变量训练/校准交付、七变量解释和遗传/MRI增量比较保持完成。原课程Python功能进入维护。本轮处理的是新模型接入前仍缺少的可移植计算代码和合成推理验收。

新增[research_runtime](../research_runtime/README.md)包含固定估计器规格、人月展开、两原因24月CIF、原序列化类兼容及显式最终模型加载。现另提供固定五外折/三内折训练与嵌套校准的单一编排，支持从头训练或复用基础模型，评价函数保持原函数AST；内置构造队列可独立运行。使用独立研究依赖，课程服务继续只依赖标准库。模型清单、参数、队列、标签和折成员留在受控环境；仓库只维护源码、合成样例和构造测试。

加载前核对调用者提供的可信清单SHA256、模型文件SHA256、环境版本、列顺序和最终模型身份。两个十变量方案保留原始策略，七变量也按既定建议返回原始CIF。没有自动拟合、校准、算法选择或默认模型替换。

本仓库提供离线合成验收入口。受控主机的原Python工作台现已另接入研究审查页面：展示既有聚合指标/区间，并以独立进程调用九个最终模型进行合成计算。该本地HTTP通道不属于Java共享契约；Java/业务前端没有因此接通。输入格式只属于此Python工具，不应直接作为后端DTO定稿。Java实际接入前，需要共同确定年龄、教育、全局CDR、ADAS13、FAQ、APOE及mm3海马体积等字段的映射、来源时间与QC政策，以及研究用途/权限、任务和结果保存、故障恢复及版本固定方式。

固定基线训练/嵌套校准源码可移植交付现已完成，历史队列重建、全部比较与解释流水线仍未整体移植。构造验证不重训真实模型，也不补第2→3环节图机制或因果证据。新的训练产物有独立格式，不自动接入旧清单加载器、工作台或Java。本分支交付上述计算源码、独立依赖、构造样例与测试；受控参数与历史队列不随Git分发，源码发布不代表部署或临床准入。原PR #10只含业务日修复及聚合研究说明。
