# 固定训练样本扰动：真实跨重训解释结果

本任务对应第4环节/FR-15、FR-16。原1160人、原五折、原七/十变量和LR/RF/XGBoost保持；每折按事件分层固定五次保留80%训练人员，测试人员和缺失不变。150次新基础管线拟合（包含150套训练内预处理）、0校准/内折/全量/局部回归，480个精确分组Shapley游戏已完成。本表格阶段累计真实448基础/36校准；后续固定图225次研究完成后当前累计673/36。

六组AD结果的固定参考模型变化M均非零，六组的首位一致率均未达到100%。以十变量RF为例，在五重复均满足排名计算资格的同一1033名人员中，固定参考下首位一致率为74.83–80.15%；这说明本固定删样机制下存在训练样本敏感性，不把非零变化当成显著性检验或临床不合格阈值。参考变化和模型×参考剩余也非零，须分别报告，不能将合并差异全部归于模型。

六组原AD折外预测hash与Brier均在首个新拟合前通过；其他原因没有历史OOF hash，未声称复现该hash。旧派生CSV解析一次并投影13列、原折JSON解析一次、30旧外折模型各解包加载一次。执行前后原字节完整性hash读取另计，不称物理文件只读一次。单次执行无重试。
