# AD-CausalRisk 用户操作指南

本指南用于Windows本机四角色协作，预测使用已安装研究模型和人工资料。当前贡献图展示模型归因，不能证明个人病因或治疗效应。真实研究输入、独立验证及临床使用仍需相应证据和授权。

## 启动与登录

双击仓库根目录 `Start-AD-CausalRisk.cmd`，等待服务就绪后打开 `http://127.0.0.1:5173/login`。需要JDK21、Node.js22.12+和Python3.11/3.12。模型配置、演练账号及初始口令见[README](../README.md#快速开始)。患者使用管理员已绑定档案的账号。并排操作角色时使用独立浏览器会话，普通标签页共享登录状态。

默认使用当前仓库的持久H2演练库，正常重启后保留资料。`--care-only`跳过模型启动，`--validation-preview`在5174打开独立临时演练。Python进程退出后可再次双击尝试恢复原模型；清单或Windows用户改变时按提示正常重启。不要删除库、快照或运行状态来解决配置问题。

## 医生到患者的流程

1. 医生从「我的患者 → 新建患者档案」开始，填写普通档案编号、称呼、访视日期和来源。七项模型输入属于同一次访视：年龄、教育年限、MMSE、CDR-SB、CDR全局、ADAS-Cog13和FAQ。
2. 保存资料并质控，逐项处理阻断或缺项。在档案「预测评估」提交，核对任务状态和报告。已有访视的补录或更正追加版本，之后重新质控。
3. 从「报告复核」记录意见。向患者发布说明是单独操作，可更新或撤回；完成复核不会自动发布模型输出。
4. 医生在档案申请患者账号，管理员从「账号管理 → 患者账号申请」核对并发放。患者登录后只查看本人进度、医生说明和复诊，不读取原始量表、概率或图权重。
5. 医生安排复诊，填写日期、地点和准备事项。患者确认、申请改期或取消时以当前预约版本为准，医院处理改期前原时间继续有效。
6. 科研随访结局需要医生另行登记类型、观察日期和来源。预约确认或完成不自动成为AD结局；截止24个月前最后一次无事件记录可能仍属未知结局。

## 研究员验证获授权病例

管理员在「验证资料授权」登记项目、普通档案编号、研究员账号及授权依据，同批病例使用同一项目。研究员进入「模型验证与更新 → 获授权病例」刷新队列，选择项目和模型版本，运行24个月验证。

报告按当前授权病例、冻结输入、概率和结局/观察日期匹配。恢复授权后重新运行可复用原报告，刷新和新登录保持同一身份。病例或结局变化且没有匹配报告时，需要运行验证。每次核对冻结条数和快照摘要。

「演练计算完成」仅表示人工描述指标完成。「样本或分组不足」保留报告并抑制指标：任一非空的风险区间与结局交叉组少于5例时，指标为空。「待补独立验证资料」表示正式验证所需方案尚未就绪。

项目验证授权不直接开放普通档案的原始资料，不能从获授权队列跳过原始数据权限检查。

## 研究员从测试CSV到报告

1. 在「数据导入」下载档案、访视和特征模板，使用同一 `DEMO-` 编号。先导入档案，再导入访视和特征。UTF-8单文件最多30000字节，每次一种表。
2. 上传仅预检，查看有效行与错误行。点击「确认入库」才保存有效行，错误行不写入；只修正并重传失败行。
3. 在「数据质控」切换到「测试样例」，按编号查找并检查。更正资料后重新质控。
4. 回到「数据导入 → 生成七变量测试快照」。模板填写同编号、同访视日期和五项补充字段；MMSE与CDR-SB读取已保存访视。先预检，再保存通过的快照。
5. 进入「模型验证与更新 → 研究工具 → 研究表格评估」，选择受试者及已同步快照。保存成功提示中的「研究资料」对应此入口。
6. 勾选一个或多个快照执行「批量评估」，批量范围是当前受试者的多个快照。已有任务直接回读，不重复提交。
7. 「评估任务」「评估报告」和「评估贡献图」切换到「测试样例」查看。默认「受控研究」不会列出DEMO资料。打开对应报告可导出PDF或HTML。

已训练模型的七项数值范围含上下界：

| 字段 | 范围 |
| --- | --- |
| 年龄 | 0–120岁 |
| 教育年限 | 0–40年 |
| MMSE | 0–30 |
| CDR-SB | 0–18 |
| CDR全局 | 0–3 |
| ADAS-Cog13 | 0–85 |
| FAQ | 0–30 |

越界请求拒绝，CSV显示INVALID；合法null保留缺失，不截断或填0。模型允许的缺失策略可能使不完整测试快照仍能计算，因此任务完成不代表输入完整。APOE或MRI入库也不表示七变量模型使用这些字段。真实研究资料继续走获授权来源和宿主准入流程。

## 患者备忘与授权

患者从「我的备忘」保存原文，再打开「查看／生成卡片」。预览问题、答案和出处，核对时间、人物、条件和否定词后确认本批卡片。修改原文后重新预览，旧卡片清除。到期时从「去复习」回忆并反馈，支持更正或删除卡片。原文过长时按提示拆分，不能删掉限制条件来强行通过。

授权页维护科研使用和随访联系选项。撤回科研使用后，本人病例退出研究员验证队列，相应报告按当前权限过滤。恢复授权后请研究员重新运行当前快照。此操作不会把患者资料自动送入训练。

## 排查和使用边界

打不开入口时先看启动窗口及 `runtime/desktop/` 本次日志。模型未就绪时仍可处理已有档案和报告。研究员找不到结果时先核对资料范围、项目、模型及账号权限；模型失败不显示替代概率。

共享故障信息时记录时间、角色、步骤和追踪号，去掉患者身份、口令、令牌及私有路径。数据库升级前备份，MySQL目标环境、崩溃恢复、并发容量、医院接口和临床效果分别验收。更多技术边界见[后端验收](Backend_Requirements_Acceptance.md)与[研究主线](Research_Core_Principles.md)。
