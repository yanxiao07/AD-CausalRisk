## 固定统计选择器

对全训练资格集及每个有放回样本，分别重新计算十列平均秩，同值赋平均秩。抽中同一个人多次时，其原值按抽中次数重复，参与样本秩和协方差；不同人员数仍按原ID计，不能把重复副本当独立新人员。

令n为当次抽样行数，对各列秩按当次样本均值和ddof=1标准差标准化为Z，规定：

```
R = Z.T @ Z / (n - 1)
Rλ = 0.9 R + 0.1 I₁₀
Ω = solve(Rλ, I₁₀)
s(u,v) = -Ω(u,v) / sqrt(Ω(u,u) Ω(v,v))
选中(u,v) ⇔ |s(u,v)| ≥ 0.20
```

这称为**项目预定的正则秩精度分数**。即使没有分布假设也可按定义计算，但不将它解释为条件独立检验、直接效应、因果强度或显著性。固定0.1正则化有助于定义统计量；由R为半正定，`aᵀRλa ≥ 0.1 aᵀa`，在非恒定列条件下数学上可逆。数值求解仍须核验有限值、对称性、残差和正对角；数值失败即停止，不换正则化救结果。不得用测试表现调0.1或0.20。

数值对称误差和求解最大绝对残差上限均为1e-10，精度对角须严格正，分数须有限且绝对值≤1；不裁剪分数、不换正则化。只取11个候选对的分数；未候选关系不作检验或零关系结论。分数对称，`s(u,v)=s(v,u)`，所以即使频率为1也不能据此认定u→v而非v→u。零分数不证明无因果，非零分数也可能受共同原因、选择和测量影响。

## 受试者Bootstrap、分母与停止

每个可估外训练折独立安排100次有放回受试者抽样，每次抽N人次，N固定为该折原资格人数。使用`PCG64(SeedSequence([20261102, fold, replicate]))`，fold为1—5，replicate为1—100，保留原资格集行序，不按事件分层或读取结局。不在全队列先算秩/分数再切折。

当次不同人员少于20，或十列任一秩方差为0，该次对全部11候选共同记不可估；不重抽、不将不可估当未选中。身份/边界、非有限输入或数值求解故障为硬停止，不能混成正常不可估后继续。各可估折完成全部预定抽样后，至少90次共同有效才可报告频率；89次即使全部选中，也不可报“100%稳定”。

每边按同一有效重复集合计算`q=选中次数/有效次数`；同时保留预定、有效、不可估数。正/负次数只计选中重复，符号一致率为`max(正次数,负次数)/选中次数`；未选中时该比率为null，不补0或1。

一个关系被标为“本折稳定候选”，须同时满足：

1. 全训练资格及至少90次有效重复成立。
2. 选择频率q≥0.80。
3. 已选中重复的符号一致率≥0.90。
4. 全训练样本的绝对分数≥0.20，且其符号与重采样主导符号一致。

各等号均纳入。频繁选中但正负冲突单列，不用绝对值掩盖符号不稳定。全训练分数与重采样频率矛盾也保留，不选对自己有利的一项。

五折分别报告，训练集重叠，不能合并成500次独立重复或总体概率/置信区间。仅当五折均可估时给出稳定候选的描述性交集；一折不可估则跨折交集为null，不丢掉该折或挑最佳折。不可估折仅保留原因、资格区间及预定/有效/不可估次数，其边分数、选择/符号次数、频率、符号一致率和保留标记均为null。可估折中零选中则频率0、保留false、符号一致率null，两种情形不能混同。频率不是因果概率，0.80/0.90没有自动的FDR或家族错误率含义。

后续上限为5次全训练分数估计+500次抽样分数估计，最多505次统计估计尝试；不可估/硬停止均不另补次数。统计估计与预测拟合分开记账，预测/预处理模型/校准拟合、权重加载和CIF预算均为0。固定真实运行已完成505次统计调用，详细可估限制见接口文档；此处不授权重复计算。
