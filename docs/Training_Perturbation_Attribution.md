## 训练子集

`research_runtime.training.subject_subsample(frame, train_positions, test_positions, fold=..., replicate=...)`接收调用方已验证的原五折之一。两组原位置必须完整、不重复、无交集；每个原训练事件类别保留`floor(0.8*n)`名受试者，无放回抽样。随机源为PCG64，种子为`20261028+100*fold+replicate`，折和重复均限1到5。同一折/重复跨算法与规格共用选择。

返回独立副本（已重置行索引）和原位置，不拟合、不保存、不生成新外折。某类无法保留至少1人就拒绝，不重抽。它是条件删样敏感性分析，不是bootstrap置信区间估计。调用方仍负责原折身份、受试者授权、特征资格和同人比较。

底层训练继续使用`fit_base`，不能调用包含内折/全量/校准的完整训练入口来冒充仅基础重训。`Journal(..., limits={'predictive': ..., 'calibration': 0})`允许明确尝试上限；旧调用的默认预算保持。每次拟合前记账，达到上限即拒绝。

## 同模型使用不同参考

`table_explanation.explain_shapley`新增可选参数`reference_values`：按规格字段顺序的一维、有限、原量纲中位数向量。它只替换观测单元，NaN/联合海马组保持，模型插补器和权重不变。提供显式向量时`reference_kind`须为默认`median`；来源资格由调用方认证，接口不会认证外部参考来自训练集。

不传该参数时仍使用本模型已存训练人月中位数或均值。输出的`reference_policy`区分缺省训练参考与调用方显式参考；原模型/输入改写拒绝及调用预算保持。该参数不扩展LIME，不改变HTTP或真实输入准入。

例如，用原模型`f0`和训练子集模型`fb`，分别取得原训练中位数`r0`和子集中位数`rb`，对同一测试快照执行：

```python
from research_runtime.table_explanation import explain_shapley

A = explain_shapley(f0, test, spec, reference_values=r0)
B = explain_shapley(fb, test, spec, reference_values=r0)
C = explain_shapley(f0, test, spec, reference_values=rb)
D = explain_shapley(fb, test, spec, reference_values=rb)
```

对每个人/组/原因的有符号贡献，模型变化为`B-A`，参考变化为`C-A`，交互剩余为`D-B-C+A`，总变化为`D-A`，逐元素核对总变化等于三项之和。不能将各项L1范数相加，也不能将该分解称为个人病因或治疗效果。模型部分包括重新拟合的预处理与缺失指示，不只是分类器系数。

## 流式内存编排

`table_xai_study.evaluate_training_perturbations`接收已验证的内存队列、原折、30个原外折包加载回调、候选清单和六份AD OOF/Brier预期值。它不读取文件、不认证来源/授权、不保存参数；默认训练回调直接委托既有`fit_base`，不运行内折、校准或全量训练。

原六份AD门槛全部通过后，才按规格/算法/折处理原模型A和五次B/C/D。每次子集只在相应训练人员中抽取；核对重新学习的中位数、缺失指示和标准化原量纲均值。中位数/指示器精确比较，均值使用`atol=rtol=1e-12`以容纳求和内存布局差异；这不是修改原OOF或归因重构门槛。

每次CIF由现有适配器的`evaluation_event(phase, rows)`在调用前后分别发送`attempt`/`complete`，尝试预算在运算前记账。训练也在回调前记尝试；其内部Journal只允许一次predictive声明。错误直接抛出，不重试、不返回部分科学成功，progress回调可保留计数与已完成折的聚合摘要。进程硬时间/内存停止、一次输入缓冲及可信解包仍由受控宿主负责；单凭本API的软资源检查不能代替外部执行封装。

新模型用完即释放，贡献矩阵仅保留当前折的五重复。跨折仅保留用于精确经验分位数的人员级标量缩减值，最终只返回汇总。排名使用两游戏共同active组；少于3组、常量秩、首位并列和Top-2边界并列各自记录。前两项内部并列不影响Top-2集合，第二/第三项并列使集合未定义。另在所有重复共同active组上重算排名，并按五重复均有资格的同一人员集合报告每重复指标；5800人员×重复配对不能当作5800名独立受试者。

返回六份模型规格摘要、30份折级训练覆盖诊断、各重复M/R/I/T的L1与经验范围、固定原IPCW权重的Brier上下文、操作计数和数值重构误差。无人员ID、原位置、输入、预测、贡献、掩码或个人hash。AD/其他原因分别报告，跨规格不据排名一致率宣称输入增益。

模拟调用必须设置`constructed=True`并提供构造回调：状态为`CONSTRUCTED_TRAINING_PERTURBATION_MATRIX_COMPLETE`，`predictive_fits=null`，150个回调槽位不能当实际拟合。真实执行的宿主应使用已绑定的默认训练/归因实现，不能通过把模拟标记改为false来认证训练、授权或临床有效性。
