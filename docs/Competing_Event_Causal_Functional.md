# 竞争事件与干预风险：已知概率核的有限状态验证

本任务对应研究主线第2→3环节：因果图提出的干预机制如何转成明确的风险功能量。已完成标准库精确概率实现和12项构造检查；没有读取病例、加载研究模型、拟合或估计ADNI效果。结果仅针对规定的人工概率模型，不能给当前先验图或预测器补上因果身份。

## 独立问题与复用边界

问题是：即使没有删失、且知道干预下的事件概率，较低的AD首次事件累计发生风险是否必然表示AD病程获益？若干预影响中间历史，计算应该传播哪些变量？

这里直接假定完整观察和已知干预概率核，不重复既有观察分布非识别反例、个人反事实耦合论证、删失来源审查或结局补全界限。现有CIF算子、先验图阴性比较和855次解释评价保持原样。本任务没有提出新的临床干预或重新评价原预测器。

既有来源映射确定的是原1160人**记录诊断的首次竞争事件**：cause 1为AD，cause 2为其他病因痴呆，不是死亡；事件日是记录诊断日。其他病因痴呆在此终点中吸收，是因为目标只统计首次事件，不能据此声称其在生物学上阻止以后发生AD。若目标改成“24月内任何时候出现AD”，就须重新定义多状态结局和来源，不能套用这一首次事件CIF。

## 固定目标、时间与假设

抽象人群在时间零点尚未发生两种首次事件；初始状态分布为p(L₀)。每一离散区间按如下顺序：先有当前历史状态Lₜ，按策略gₜ(a|Lₜ)分配行动Aₜ，再发生互斥的首次事件1、首次事件2，或保持无事件并转移至Lₜ₊₁。事件状态在**首次事件过程**中吸收；同区间内的事件优先级必须已包含在互斥分类中。本实现不从日期或临床表推断优先级。

Lₜ必须编码核与策略所需的全部历史；有限状态表示隐含这一充分性要求，不表示当前十变量已满足它。程序支持时变状态和随机策略，不支持隐含的历史记忆、未建模的重复事件、连续时间或自动选择调整集合。

若g₁与g₀是定义充分的干预策略，目标是选定人群中

`P(在H前首次事件为AD，策略g₁) − P(在H前首次事件为AD，策略g₀)`。

这是一种总风险对比，包含竞争事件改变首次AD发生机会的通路。若要把观察数据的条件分布代入作为干预核，还需论证行动的序贯交换性、适用历史下的正值性、一致性和版本明确、正确时间顺序/测量及观察机制；在首次MCI入组人群中成立的目标也不自动推广到其他人群。代码不检查这些科学假设。已知SCM的人工概率核可以直接代入；预测器的两原因危险率、注意力或输入替换不能据此自动代入为干预核。

风险、消除竞争事件下的风险和危险率对比对应不同目标。其因果解释与条件见Young等的[原始方法论文](https://pubmed.ncbi.nlm.nih.gov/31985089/)（2020，DOI 10.1002/sim.8471）。本文将这一框架应用于当前首次事件标签的判断属于项目侧推理，文献不替项目认证识别。

## 功能量和Python接口

令qₜ(l)为区间开始时仍无事件且历史为l的概率质量。核包含互斥的两种事件概率kₜ(1|l,a)、kₜ(2|l,a)，以及**联合质量**kₜ(0,l′|l,a)。每行全部质量和为1。递推为：

```text
ΔFⱼ(t+1) = Σₗ,ₐ qₜ(l) gₜ(a|l) kₜ(j|l,a), j∈{1,2}
qₜ₊₁(l′) = Σₗ,ₐ qₜ(l) gₜ(a|l) kₜ(0,l′|l,a)
Fⱼ(t+1) = Fⱼ(t) + ΔFⱼ(t+1)
F₁(t) + F₂(t) + Σₗqₜ(l) = 1
```

实现位于[competing_event_functional.py](../research_runtime/competing_event_functional.py)，仅接受不可变tuple和精确`Fraction`/整数概率。浮点数、负概率、和不为1或维度不一致均拒绝；不会自动归一化、把竞争事件当删失、补缺失核或消除某条通路。包括不可达状态在内的核都须显式定义；这不认证观察数据具有该状态/行动的支持。

```python
from fractions import Fraction as F
from research_runtime.competing_event_functional import Transition, evaluate_known_policy

# 一个历史状态，一个行动，两个任意离散区间；不是实际月度病例估计。
row = Transition(event1=F(1, 10), event2=F(3, 10), free=(F(3, 5),))
curve = evaluate_known_policy(
    initial=(F(1),),
    kernels=(((row,),),) * 2,
    policy=(((F(1),),),) * 2,
)
assert curve[-1].event1 == F(4, 25)
assert curve[-1].event2 == F(12, 25)
assert curve[-1].all_event + sum(curve[-1].free) == 1
```

返回基线和每个区间的两原因累计质量、增量及按历史状态划分的无事件质量。程序没有读取器、模型接口、优化器、效应认证开关或HTTP入口；不会改动原CIF算子或图权重。

## 精确人工例子

以下均是完全规定的抽象概率，不是参与者结果或经验估计。两行动可在同一人工SCM内对应两套已知核；这些行动没有被命名为实际药物、基因修改或认知分数治疗。

| 两区间规定模型 | AD危险率 | 其他首次事件危险率 | AD首次事件风险 | 任一首次事件风险 |
| --- | --- | --- | --- | --- |
| 相同AD核，原竞争机制 | 0.10 | 0.30 | 0.16 | 0.64 |
| 相同AD核，另行规定竞争概率为0 | 0.10 | 0 | 0.19 | 0.19 |
| 符号反转例，参考行动 | 0.10 | 0.10 | 0.18 | 0.36 |
| 符号反转例，另一行动 | 0.12 | 0.60 | 0.1536 | 0.9216 |

前两行只改变竞争概率就改变AD CIF；后两行的AD危险率方向与AD CIF方向相反，同时任一事件风险大幅上升。仅报告较低AD CIF会遗漏竞争结局。这不是说风险对比失效，而是必须按所定义的总风险目标解释，不能直接称AD病程获益。

把竞争概率设为0并将其质量移到无事件状态，**是在另行规定一个概率模型**。保留其余核需要额外机制假设，观察到的危险率一般不能自动识别现实中“消除其他痴呆”的风险或控制直接效应。本程序没有提供从两原因预测危险率自动生成因果直接效应的功能。

另一个两状态例中，首个行动改变L₁，L₁再决定次区间事件1概率（1/4或3/4），所有人完整观察且没有竞争事件。正确传播L₁后，两策略风险为1/4和3/4，差1/2；把L固定在基线会在两臂都得到1/4。该构造验证图中中间历史的实际传播，不证明ADNI存在这条通路。即使未来总效应被识别，个体两种潜在结局仍不能由本功能量恢复。

单状态、恒定两原因危险率下，H区间解析真值为

`F₁(H)=h₁/(h₁+h₂)·[1−(1−h₁−h₂)^H]`（两危险率和大于0）。

24区间亦按这个式子精确核对；24仅是构造长度，不把概率解释为本研究24月结果。
