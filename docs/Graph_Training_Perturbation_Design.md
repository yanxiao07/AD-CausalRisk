# 现有图约束的训练人员扰动设计

设计、原语、流式编排及225次真实固定研究均已完成。方法按本页固定规格执行，实际结论与限制见[真实结果](Graph_Training_Perturbation_Results.md)。

本任务对应第2→3→4研究环节：固定现有三臂图模型，评价训练人员改变后，同一测试人员的风险预测与有序解释变化。固定研究已完成；它提供本删样机制下的预测/解释敏感性结果，不识别个人因果。

复用原1160人、十变量回顾性快照、五折、11先验路由和唯一语义置换。self_only、prior、semantic_permutation均保留三初始化20260926/27/28和原40epoch优化规格。旧图增益未确立、原解释顺序敏感的结论保持。表格150次真实删样研究已完成，它不替代本项图模型研究。

每折按事件分层，无放回保留各层floor(80%人数)，五次固定抽取；25个子集在全部臂/初始化间共用，测试人员及缺失不变。训练种子保持原值，抽样复用training.subject_subsample。原其他原因5事件、每子集3事件，保持稀疏性限制。

| 量 | 定义与验收边界 |
| --- | --- |
| 预测策略 | 先平均三种子两原因CIF，保持原主预测策略；不先平均logit、绝对变化、排名或Brier |
| 训练配对 | 三臂同初始化/批次/训练输入；子集人月内重新学习中位数与标准化。删样改变优化暴露，不能称纯参数不确定性 |
| 主终点 | AD逐人绝对均值CIF漂移；每重复在全部1160人计算prior减自环、prior减语义置换的配对差 |
| 解释方法 | 原九组正/反序CIF分解，双侧海马联合、缺失保持；每种子分解后先平均有符号贡献，各顺序分别报告 |
| 四游戏 | A=原模型/原参考，B=新模型/原参考，C=原模型/新参考，D=新模型/新参考；参考为各自训练人月原量纲中位数 |
| 分解 | M=B−A，R=C−A，I=D−B−C+A，T=D−A；逐人逐组核对T=M+R+I和各游戏输出重构≤1e-12；各项L1不相加 |
| 比较分母 | L1/预测漂移全部1160人；排名另按原因/比较/指标，在三臂×两顺序×五重复共同计算资格人员中比较并报告人数 |
| 不可估计 | 少于3共同active组、常量秩、首位或Top2边界并列保留原因；1e-12并列和1e-6符号门槛保持 |
| 不确定性 | 五次固定条件删样的经验范围，没有总体/个人置信区间、p值或因果识别；两顺序不混平均，逐种子只作描述 |
| 性能背景 | 原训练KM/IPCW固定，对种子均值CIF计算Brier；稳定常量预测器可以很差，不据稳定性选默认、改写旧增益结论 |

固定执行范围为225次基础拟合（含225套图预处理）、0校准/内折/全量/局部回归。45旧外折参数各加载一次，首个新拟合前通过24个两原因OOF hash与12个AD Brier门槛；9全量模型不加载。原派生CSV解析一次13列及原折JSON解析一次，完整性字节hash读取另计，0新RDA/其他表。

240个三种子游戏对应720个单模型/参考游戏，每个参考与正反序中间状态17次CIF，共12,240；旧45/新225各完整预测和结束重放一次，另540，总12,780 CIF。最多2,964,960受试者状态行，内部24月展开71,159,040个人月。六小时/2GiB、单拟合300秒和累计拟合14,400秒为本次固定执行的停止上限；研究计算实测约4259秒。任何身份/配对/概率/副作用/忠实性/预算失败保留不完整，不重试或改规格。新模型按子集使用后释放，仅保留聚合与操作计数。

原生图估计器、人月/CIF、抽样和排名原语直接复用。显式跨参考/逐次记账在graph_explanation中实现，单次受控拟合在graph_training中实现；原run_graph_comparison包含保存及全量拟合，不用于本预算。graph_native.py与graph_protocol.json保留原始字节，保证旧归档身份校验。接口见[原语](Graph_Training_Perturbation_Primitives.md)及[编排](Graph_Training_Perturbation_Streaming.md)。

本设计不是新训练的授权回执。原图方向仍为预测先验，未识别个人因果；固定删样结果即使稳定也不改变回顾性MRI、as-of/QC/ICV/扫描仪、独立及临床限制。正反序分解不称Shapley/LIME，中位数组合不视作真实干预。
